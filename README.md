# Project Overview

A UI/UX replication of the Instagram mobile application designed in Figma, focusing on a clean, familiar, and user-friendly interface.

# Objectives
- Recreate the Instagram-style user interface
- Practice UI/UX design principles
- Improve skills in Figma components and prototyping
- Create a consistent and responsive mobile design

# Features
- Social media feed
- Story section
- Search and explore
- Post creation
- User profile
- Interactive navigation

# Design Highlights
- Clean and minimal layout
- Consistent Inter typography
- Simple and recognizable icons
- Proper spacing and alignment
- Reusable Figma components
- Smooth and intuitive navigation
